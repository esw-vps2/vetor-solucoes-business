# Code quality tooling

Formatting is enforced by `.prettierrc` and `.editorconfig`.

Shared TypeScript naming and type conventions are defined in
`.cursor/rules/typescript-style.mdc`.

Database naming is defined in `.cursor/rules/postgres.mdc`, and source-code
comments are governed by `.cursor/rules/no-comments.mdc`.

Change evidence, tests, security review, and commit conventions are governed
by `.cursor/rules/quality-gate.mdc`.
